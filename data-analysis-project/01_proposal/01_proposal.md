# 데이터분석 프로젝트 1차 기획안

1. 프로젝트 제목

전국 교통사고의 유형별 발생 현황, 인명피해 및 지역별 특성 분석


2. 프로젝트 배경 및 목적

올해 크지 않은 교통사고를 몇 차례 경험하면서 교통안전이라는 주제에 관심이 갔습니다

평소 운전하면서 어떤 종류의 교통사고가 많이 발생하는지, 사고유형에 따라 인명피해는 얼마나 다른지 궁금했습니다. 또한 이러한 사고들이 지역별로 어떤 차이가 있고, 시간이 지나면서 어떻게 변화해 왔는지도 알아보고 싶었습니다.

이번 프로젝트에서는 한국도로교통공단에서 제공하는 실제 교통사고 통계자료를 활용하여 최근 10년간의 교통사고 발생 현황과 변화를 분석하려고 합니다.

사고유형별 특징과 사망자수, 지역별 차이를 함께 분석하여 교통사고 통계에서 어떤 의미를 찾을 수 있는지 확인하는 것이 목적입니다.

3. 핵심 분석 질문

Q1. 교통사고는 사고유형별로 얼마나 발생하며, 최근 10년간 발생 건수와 비중은 어떻게 변화했는가?

- 사고유형별 발생 건수 비교
- 전체사고 대비 각 사고유형의 비율 확인
- 2016~2025년 사고유형별 증가·감소 추이 분석

Q2. 사고유형별 사망자수는 어떻게 다르며, 최근 10년간 어떤 변화가 나타났는가?

- 사고유형별 사망자수 비교
- 2016~2025년 연도별 사망자수 변화 분석

Q3. 지역별 교통사고 발생 현황에는 어떤 차이가 있으며, 최근 10년간 어떻게 변화했는가?

- 지역별 사고건수 비교
- 지역별 사고 발생 추이 및 변화 분석

4. 데이터 확보 계획

데이터 출처
- 제공 기관: 한국도로교통공단
- 데이터명: 지자체별 대상사고 통계정보
- 데이터 출처: https://opendata.koroad.or.kr/api/selectSttDataSet.do
- 확보 방법: 공식 데이터 제공 페이지에서 CSV 파일 다운로드 완료
- 원본 파일명: `교통사고_data.csv`



5. 예상 데이터 구조

한국도로교통공단에서 제공하는 교통사고 통계 CSV 데이터를 사용할 예정입니다.
주요 데이터 항목은 다음과 같습니다.

- 연도
- 지역(법정동코드)
- 사고유형
- 사고건수
- 사망자수 및 부상자수
- 치사율 및 인구·자동차 대비 사고건수

6. 예상 분석 방법

Python의 Pandas를 활용하여 데이터를 정리하고, Matplotlib이나 Seaborn으로 주요 결과를 시각화할 예정입니다.

사고유형별 발생 건수와 사망자수를 비교하고, 연도별 변화와 지역별 차이를 살펴보려고 합니다.

필요에 따라 기초 통계분석을 진행하고, 데이터 특성에 적합하다면 머신러닝을 활용한 예측 분석도 검토할 계획입니다.

7. 생성형 AI 활용 계획

프로젝트 진행 과정에서 생성형 AI를 다음과 같이 활용할 계획입니다.

- 데이터 구조와 품질 확인을 위한 코드 작성 보조
- 적절한 통계분석 및 머신러닝 방법 검토
- 코드 오류 원인 파악과 수정
- AI가 작성한 코드와 분석 결과를 실제 데이터와 비교하여 검증
